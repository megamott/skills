# Работа с репозиторием

Это коллекция скиллов, устанавливаемых через `npx skills`.

- Храни каждый скилл в `skills/<name>/SKILL.md`. `name` совпадает с каталогом: строчные латинские буквы, цифры и одиночные дефисы, максимум 64 символа.
- В YAML-заголовке обязательны непустые `name` и `description`. Описание должно объяснять, когда применять скилл.
- При создании скилла выбирай режим вызова. Для запуска только пользователем ставь `disable-model-invocation: true` и `policy.allow_implicit_invocation: false` в его `agents/openai.yaml`. Для автоматического вызова эти ограничения не добавляй.
- Держи вспомогательные документы и шаблоны внутри каталога скилла. Делай скиллы самостоятельными; необходимые зависимости на другие скиллы описывай явно.
- При добавлении, переименовании или удалении скилла синхронно обновляй каталог README и массив `skills` в `.claude-plugin/plugin.json`. Пути в манифесте имеют вид `./skills/<name>`.
- При изменении поведения обновляй описание и связанные примеры. Проверяй скилл на характерной задаче в новой сессии агента.
- Проверяй обнаружение командой `npx skills@latest add . --list`. При пустой коллекции отсутствие скиллов ожидаемо. Манифест можно проверить через `claude plugin validate .claude-plugin/plugin.json --strict`.
- Для локальной разработки используй `node scripts/link-skill.mjs <name> <каталог-установки>`. Скрипт должен сохранять существующие установки и отказывать при конфликте.
- Разрабатывай изменения в ветках; `main` содержит готовые скиллы и служит источником обычной установки.
- Версия общая для коллекции, хранится в `.claude-plugin/plugin.json`. GitHub Release создаётся вручную с соответствующим тегом `v<version>` по инструкции README. Опубликованные теги не изменяй.
- Локальные `.agents/`, `.claude/`, `.serena/` и `skills-lock.json` относятся к рабочему окружению. Публикуемые скиллы находятся в `skills/`.
- Сохраняй простой каркас: новые зависимости, генераторы и автоматизацию добавляй при конкретной необходимости.
- Редактируй инструкции здесь; `CLAUDE.md` должен оставаться относительным симлинком на `AGENTS.md`.
