# Megamott Skills

Коллекция скиллов для AI-агентов. Установка через [skills](https://github.com/vercel-labs/skills), версии коллекции через GitHub Releases.

## Установка

```sh
npx skills@latest add megamott/skills
```

Установщик предложит выбрать скиллы и агентов. Для установки одного скилла нужно добавить `--skill <имя>`.

## Каталог

| Скилл | Описание |
| --- | --- |
| [review-code](skills/review-code/SKILL.md) | Код-ревью по правилам проекта и требованиям задачи: ошибки, нейминг и простота кода. |

## Разработка и проверка

Для проверки списка доступных скиллов нужно выполнить команду из корня репозитория:

```sh
npx skills@latest add . --list
```

Для локальной проверки нужно подключить выбранный скилл из рабочей копии через симлинк:

```sh
node scripts/link-skill.mjs review-code ~/.agents/skills
node scripts/link-skill.mjs review-code ~/.claude/skills
```

Второй аргумент задаёт каталог установки. Например, `.agents/skills` вместо `~/.agents/skills` подключит скилл только к текущему проекту. Скрипт создаёт симлинк, проверяет конфликты и допускает повторный запуск для той же ссылки.

Изменения читаются из рабочей копии; после правки нужно начать новую сессию агента и проверить скилл на характерной задаче. После переименования нужно удалить старую ссылку и создать ссылку с новым именем. Для отключения достаточно удалить созданный симлинк, например `unlink ~/.agents/skills/review-code`.

Новые версии нужно разрабатывать в отдельных ветках. В `main` следует вливать готовые изменения: пользователи обычной команды установки получают именно её содержимое.
